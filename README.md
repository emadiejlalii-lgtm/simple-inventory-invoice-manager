# Simple Inventory & Invoice Manager

A lightweight open-source starter project for managing products, inventory, customers, and sales invoices.

## Features
- Product and inventory management
- Customer records
- Sales invoice structure
- Simple dashboard foundation
- Easy to extend and customize

## Project Goal
This project aims to provide a simple, accessible foundation for small businesses that need an easy way to organize products, customers, and sales.

## Status
Active development. The project is currently a lightweight MVP and will be expanded based on user feedback.
